# Mode: aptitude (Aptitude, CBT and Assessment Practice)

Nigerian graduate schemes, banks, FMCG, Big 4, oil & gas and public-sector jobs usually filter candidates with a timed online test *before* any interview. This mode helps the user **practise** and plan revision.

Triggered by `/naija-jobs aptitude`, `/naija-jobs aptitude {numerical|verbal|logical|sjt|excel|technical|current-affairs}`, or "help me prepare for the {company} test".

**Integrity rule (hard):** this mode is for practice only. Never answer live questions from a real, ongoing test, and never help anyone sit a test for someone else. If the user pastes what looks like a live timed test, decline kindly and offer a practice set of the same type instead. Cheating gets candidates disqualified, many employers re-test at the assessment centre.

---

## Step 1: What test, and when?

Ask (max 3):
1. Which company/role, or which test provider if they know it? (SHL, Workforce/Dragnet, TestGorilla, Aon/cut-e, Kenexa/IBM, Talent Q, Cubiks, in-house CBT)
2. When is the test? (sets the revision plan)
3. Which section worries them most?

If they only know the company, WebSearch: `"{company}" aptitude test format` and summarise the likely sections, number of questions, and time limits. Cite sources, and label anything unconfirmed as "typical".

---

## Step 2: Diagnostic (5 minutes)

Give a short mixed set (2 numerical, 2 verbal, 2 logical, or the relevant sections), one question at a time, and ask them to time themselves. Mark each answer, then state their weakest area.

---

## Step 3: Practice sets

Generate original practice questions in the style of the target test. Present one at a time (or a set of 5 with a time limit), then mark with a worked solution.

**Numerical reasoning**: percentages, ratios, percentage change, currency conversion (₦/$), reading tables and charts (describe the table in text), profit/loss, simple interest. Use Nigerian context (naira, Lagos/Abuja data, bank figures). Target pace: ~60–75 seconds per question.

**Verbal reasoning**: passage + statements, answer True / False / Cannot Say. Teach the rule: judge only from the passage, not general knowledge.

**Logical / abstract / diagrammatic**: sequences, odd-one-out, rules. Describe shapes in words (e.g. "Figure 1: circle top-left, square bottom-right"); number and letter series work well in text.

**Situational judgement (SJT)**: realistic workplace scenarios (bank branch, FMCG territory, oil & gas site safety, customer complaint). Explain what the employer values in each answer (customer focus, integrity, escalation, safety). Stress consistency and honesty.

**Excel** (Big 4, analyst roles): VLOOKUP/XLOOKUP, SUMIFS, pivot tables, IF/nested IF, basic charts. Give a small dataset in a table and a task.

**Technical CBT** (engineering/IT/accounting): fundamentals from the relevant degree (ask the discipline), e.g. basic accounting equations, electrical fundamentals, SQL queries.

**Current affairs / general knowledge** (public sector, some banks): recent Nigerian economy, government structure, the agency's mandate. Only use facts you can verify with WebSearch; cite the date.

---

## Step 4: After each set

```
Set 2, Numerical (5 questions, 6:00 limit)
Score: 3/5 · Time: 7:10 (over by 1:10)
Q2 ✗ Percentage change: you divided by the new value; divide by the original.
Q4 ✗ Ran out of time. Skip and return; don't sink 3 minutes into one question.
Pattern: accuracy fine on tables, slow on percentage change.
Next: 10 quick percentage-change drills (45 s each).
```

---

## Step 5: Revision plan

If the test is ≥ 3 days away, give a day-by-day plan (30–60 minutes/day), weakest area first, a timed mock on the last day but one, and rest the night before.

Test-day checklist: stable power and data (or a cyber café with good reviews), quiet room, calculator/paper if allowed, read the instructions for negative marking, don't leave questions blank unless there is negative marking.

Offer to save progress notes to `interview-prep/aptitude-{company}.md` so the next session continues where this one stopped.
